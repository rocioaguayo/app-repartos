# App Repartos 🚚

Aplicación web para la gestión de envíos y seguimiento de pedidos, diseñada para administradores y repartidores.

## 🚀 Demo en Vivo
Puedes acceder a la aplicación desplegada en el siguiente enlace:
[https://rocioaguayo.github.io/app-repartos/](https://rocioaguayo.github.io/app-repartos/)

## 🛠️ Tecnologías Utilizadas
* HTML5 / CSS3 / JavaScript
* GitHub Pages (Hosting)

## 📋 Funcionalidades
* Panel de administración (`panel-admin.html`)
* Dashboard para repartidores (`dashboard-repartor.html`)
* Vista de pedidos (`ver-pedidos.html`)
* Inicio de sesión (`login.html`)
